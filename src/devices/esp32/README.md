# Tích hợp ESP32

ESP32 dự kiến thực thi lịch ngay cả khi trình duyệt đóng. Chuẩn bị kênh xác thực thiết bị, mã lệnh duy nhất, xác nhận kết quả và cơ chế khóa chu trình ngay trên thiết bị. Giữ quy tắc lịch theo ngày và API ứng dụng khi bổ sung driver. Adapter Mock hiện giao việc lưu trạng thái và tiến trình cho PostgreSQL.
